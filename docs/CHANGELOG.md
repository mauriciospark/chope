# Changelog

Todas as alterações notáveis deste projeto serão documentadas neste arquivo.

## [1.0.0] - 2026-10-17

### Added
- Sistema de gestão de vendas diretas com cálculo automático de preços
- Sistema de compras indiretas com reservas e controle de retiradas parciais
- Visualização de reservas ativas com barra de progresso de consumo
- Gerenciamento de estoque com opções de adicionar ou definir total
- Histórico completo de vendas diretas e reservas finalizadas
- Configuração de preços flexíveis (unitário, caixinha, tamanho da caixa)
- Funcionalidade de exportação de dados em formato JSON para backup
- Funcionalidade de importação de dados a partir de arquivo JSON
- Suporte a dark mode automático via preferências do sistema
- Indicador visual de estoque baixo (≤10 unidades)
- Display de logo do projeto ao lado do nome
- Estatísticas em tempo real (estoque, total vendido, latas entregues, latas guardadas)
- Sistema de reset completo de dados
- Layout responsivo para mobile e desktop

### Changed
- Interface otimizada para uso rápido e intuitivo
- Armazenamento centralizado no objeto de estado global
- Navegação por tabs sem recarregamento de página
